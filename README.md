# 绘序 · 魔女画室

**把图片、文字和灵感，画成自己的作品。**

绘序是一款面向 iPhone 的原生图层图片编辑器，采用伊蕾娜主题图标与紫蓝色界面。适合拼图、给图片写字、制作简单封面和自由涂鸦。iOS 18+，无第三方 SDK，无账号或广告。

## 主要功能

| 工具 | 当前实现 |
| --- | --- |
| 图片 | 从系统照片选择器导入，独立移动、缩放、旋转、水平翻转 |
| 图层 | 图片与文字图层，上下排序、复制、删除、隐藏、锁定、不透明度 |
| 笔刷 | PencilKit 钢笔、铅笔、马克笔，自选颜色、透明度与粗细 |
| 橡皮 | 对手绘层按完整笔画擦除，不会误擦底图 |
| 一键清理 | 只清空手绘笔迹，或清空笔迹与所有文字图层；保留图片，可撤销 |
| 文字 | 独立文字图层，编辑内容、字号、预设颜色、位置与变换 |
| 调色 | 图片亮度、对比度、饱和度、黑白及恢复原色 |
| 画布 | 正方形、横版、竖版；双指缩放与移动，边界外内容导出时裁去 |
| 撤销重做 | 当前启动期间最多 20 步，涵盖笔迹与图层操作 |
| 导出 | PNG（支持透明背景）、JPEG（白底）、可继续编辑的 JSON 工程 |
| 保存 | 本机自动保存，上次工程恢复，导入工程前确认替换 |

## 与 Photoshop 的范围区别

这是独立开发的轻量图片编辑器，使用常见的图层、画笔、变换、调色与导出工作流。**不是 Adobe 产品，也不具备完整 Photoshop 的功能。** 当前不支持 PSD、套索/魔棒选区、图层蒙版、混合模式、修复/仿制、智能抠图、生成式填充、CMYK 或专业 RAW 工作流。

手绘笔迹合为独立顶层，始终位于图片和文字上方；没有逐个笔迹图层的自由排序。橡皮按笔画擦除，不是像素橡皮。画布导出尺寸固定为所选画布尺寸，不会输出画布外的隐藏内容。

一键清理仅作用于本应用新增的手绘笔迹与文字图层；不能还原已经压进照片像素里的涂鸦或文字。

## 使用方式

1. 顶部图片按钮导入照片，或点击文字按钮新增文字。
2. “移动”模式单指拖动图层；在图层上用双指缩放或旋转。也可以在图层属性里精确调整。
3. “绘画”模式选笔刷、颜色和大小；“橡皮”擦除手绘笔画。
4. “一键清空涂鸦”选择清理范围，底图会保留。
5. “图层与调整”管理图层、修改文字、调色或开启透明背景。
6. 导出 PNG/JPEG 获得合成图；导出 JSON 保留可编辑图层和笔迹。

本机工程仅自动保存当前一份。开始新作品前请先导出 JSON；卸载前也请备份。PNG/JPEG 不保留可编辑图层。

## 容量与隐私

最多 30 个图片/文字图层；单张图片自动缩至最长边 2048 像素，全部图片最多 2400 万像素及 60 MB 编码数据。工程文件不超过 90 MB。导入只读取自行选择的图片，编辑内容不上传服务器。

文件导入导出、复杂手势、真实照片和 PencilKit 书写仍需真机验收。工程格式为本应用 JSON，不兼容 PSD。
